# Neurova AI Studio

Первая функциональная версия премиального конструктора AI-ассистентов: интерактивный лендинг, демо-боты, регистрация, тарифы, личный кабинет и пошаговый конструктор.

## Что уже работает

- создание и вход в аккаунт;
- сохранение AI-ассистентов в SQLite;
- личный кабинет с созданными ботами;
- загрузка базы знаний в `.pdf`, `.txt` или `.md`;
- тестовый чат: бот находит релевантные фрагменты в загруженном документе и показывает источник;
- копирование и работа реального виджета для внешнего сайта.

## Запуск разработки

В первом терминале:

```powershell
npm run dev:api
```

Во втором терминале:

```powershell
npm run dev
```

Откройте `http://127.0.0.1:5173`.

## Production-запуск

```powershell
npm run build
npm start
```

Откройте `http://127.0.0.1:8787`.

## Подключение настоящего AI

По умолчанию проект работает без внешних ключей: бот ищет релевантный ответ в текстовой базе знаний. Чтобы включить настоящую генеративную модель, скопируйте `server/.env.example` в `server/.env` и укажите свой ключ и модель:

```env
OPENAI_API_KEY=ваш_секретный_ключ
OPENAI_MODEL=выбранная_вами_модель
```

Ключ остаётся только на сервере и никогда не отправляется в браузер. Если AI API временно недоступен, бот автоматически возвращается к локальному режиму базы знаний.

## Подключение виджета

В кабинете нажмите «Код ↗» у созданного бота и вставьте скопированную строку перед закрывающим тегом `</body>` любого сайта. Виджет подключается по публичному API и не раскрывает ключ AI-провайдера в браузере.

Сервер сохраняет аккаунты и созданных ботов в SQLite-файл `server/data/neurova.db`. Для дипломной версии перед публикацией можно заменить локальное хранилище на PostgreSQL и подключить настоящий AI API / RAG-поиск по PDF-документам.
